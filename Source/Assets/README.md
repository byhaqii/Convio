# Convio icon

Raster icon created with the built-in imagegen tool: a large jade-green and pearl-white glass C on an opaque, edge-to-edge dark green square. The artwork has no inset tile or transparent padding; macOS supplies its own icon presentation. No third-party logo was used.

`Convio.png` is the raster master. `AppIcon.icns` contains the native macOS icon sizes and is copied into the app by `build.sh`.
