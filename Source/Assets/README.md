# Convy icon

Original raster icon created with the built-in imagegen tool: a rounded jade-green and pearl-white glass C on a dark green rounded-square tile, with transparent margins and no sharp corners. No third-party logo or reference image was used.

`Convy.png` is the raster master. `AppIcon.icns` contains the native macOS icon sizes and is copied into the app by `build.sh`.
